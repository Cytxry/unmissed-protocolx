⌂Local & OfflineChecking the local Ollama model…⌄

Unmissed runs in this local Python app and sends inference requests only to the configured loopback Ollama service. It has no cloud AI fallback. If Ollama is unavailable, analysis stays disabled and the page shows how to restore local service.

Before your first offline session

  1. Install Python 3.10+ and Ollama while online.
  2. Download the model once: ollama pull qwen2.5:3b
  3. Keep this project and its local runtime files available on the device.

After setup, analysis can work without internet if Ollama, the model, Python, and app assets are available locally. Live status checks Ollama/model availability; it does not test a disconnected network.

Start the local app

ollama serve
$env:PORT = '8080'
python app.py

Open http://127.0.0.1:8080. Python dependencies use the standard library. Internet is needed for initial installs, model downloads, and updates.

Conversation data is held in this app's process memory and sent to local Ollama for inference. No public hosting, telemetry, or remote model fallback is configured.
